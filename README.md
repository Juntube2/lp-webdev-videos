# Fábrica de vídeos do TikTok

Vídeos curtos de dicas de **Valorant** e **Fortnite** para console, montados a partir de gameplay própria,
narrados com voz grátis e agendados automaticamente no TikTok pelo Metricool.

- `fabrica/` — scripts (narrar, montar, preparar gameplay) e o manual de produção (`fabrica/README.md`)
- `gameplay/` — clipes de gameplay e `catalogo.json`
- `episodios/` — um episódio por pasta (`episodio.json` + arquivos gerados)
- `videos/` — vídeos prontos, com link público para o Metricool
- `arquivo/programacao/` — a fase anterior do canal (vídeos de programação)
